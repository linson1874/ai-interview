# 阶段六演进池（backlog-stage6）

> 立池日期：2026-11-25 ｜ 提出方：学员 ｜ 批准与维护：总导师
> **出处声明**：功能清单来自参考项目 interview-guide 的 README（学员开工前跟跑过的开源项目，机器留有 `~/.interview-guide/` 与三个 `interview-*` 停用容器为证）。学员拍板：该清单纳入本项目**后续开发**。
> **池的性质**：意图声明，**不是承诺**。池内任何条目要动工，必须走既有的立项流水线：**ROI 论证 → 合同草案（🔶决策点学员起草）→ 导师评审 → 实施 → 验收**。池的存在恰恰是为了防止清单以"顺手做了"的方式溜进当前冲刺。

## 立项三法（池规）

1. **主线优先**：前端冲刺周收官前，池内**零立项**。冲刺周的 D 阶段（手写底线、answer/report 页面卡）是当前唯一主线。
2. **逐项立项，不整包搬**：每项单独论证、单独合同。"把 interview-guide 搬进来"不是一个任务，是十几个独立决策。
3. **差异化不冻结**：池内条目全部落地的总时长，不得超过差异化资产（CAT-lite 追问决策器、提分间隔重复、评测体系）演进一次的周期——**清单是别人的护城河，你的护城河是那两样**。简历第二段写的是差异化，没人采访你"功能多"。
