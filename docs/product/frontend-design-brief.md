# 前端设计基线 v0.9（AI 初稿——待 itlzy 甲方按评审单验收，改后归学员定稿为 v1.0）

> 依据：合同 11 §0/#76 TS 纪律、brief F1-F10、页面卡断言制。本文件是**任务书不是圣旨**：
> 甲方（学员）评审通过前，任何条款可删可改；通过后它就是此后每页对话 AI 的第一附件。

## 1. 设计令牌（全局唯一定义处）
- 主色 `--el-color-primary`（不自创品牌色）；语义色仅 success/warning/danger/info 四族
- 间距节奏：8px 基数（8/16/24 三档），卡片 padding 16px，区块间 24px
- 圆角/阴影/字号：全部 ElementPlus 默认，全局覆写配额=1 次（主题色）
- 文案口径：错误文案从 error-map.ts 取（F2）；成功文案前端自有（01 §1 msg=ok）

## 2. 页面骨架规范
- 布局：单栏 960px 居中（曲线报告页 1200px 例外，写明理由）
- 每页必有：空态（图标+一句话+1 个主操作）/加载态（骨架屏优先）/错误态（EP Result+重试）
- 主操作按钮位置：右上或表单底部唯一主按钮；次要动作进 dropdown
- 状态色语言：绿=就绪（status1/2）、蓝=进行中（0/4、report 1）、灰=不可用（disabled 必配 tooltip 说明原因——F1/F7 的可视化）

## 3. 三态即合同（每页卡引用本节验收）
- 轮询态页面（面试创建/报告/复习）：进度区显示"生成中·已等待 Xs"+静默退避提示（熔断后显示"重试"按钮，不显示"请刷新"——#81 条款）
- 危险动作（rebuild 重生成）：确认弹窗必含"这会再次调用大模型"字样——成本透明纪律（09-E 精神）
- 追问树：缩进表层级+strategy 三色徽章（drill 蓝/angle 紫/scaffold 橙——X2 断言的 UI 化，色值取自 EP 语义色变量）

## 4. 禁止项（违反=评审打回，无需讨论审美）
自定义动画 / 渐变 / 第三种圆角 / emoji 当图标 / v-html（F3 铁律）/ 内联硬编码色值 / 页面私有文案（必须走 error-map 或本页文案常量）
