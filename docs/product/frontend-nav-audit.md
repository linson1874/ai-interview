## 1. 导航级缺失（3 处，按优先级排序）

### ① 历史面试/报告列表 ⭐ 最重要（后端真缺口）

- **现状**：「03 面试报告」页打开后，用户没有任何途径到达某场报告——`InterviewController` 的 7 个端点**全部按 id 操作，无列表端点**（`GET /interview/page` 不存在）。用户交卷后拿到的 interviewId 一旦离开页面即丢失，报告功能事实上不可达。
- **对照**：简历模块有 `GET /resume/page`，面试模块漏配了同款能力。
- **导师裁决（挂出待正式增补）**：后端补 `GET /interview/page`，设计纪律直接平移合同 03：
  - 归属过滤（只回自己的，越权即消失）；
  - `page/size` 校验 + size 上限 50 + 显式 maxLimit（D2 同款）；
  - 排序 `createTime DESC, id DESC`（次键防翻页漂移，D3 同款）；
  - 列表 VO 裁剪大字段（报告 summary/题目全文不进列表，只给 id/状态/总分/简历摘要/时间）。
- **流程**：此端点属合同 06 增补 → 学员起草页面卡时**连带提报合同变更**，导师批后动键盘。

### ② RAG 知识问答页（练习区）

- **现状**：后端 `POST /ai/kb/ask` 已完工（合同 08 签字），前端无入口。页脚已写"练习区"字样，说明设计里有这个概念，只是没落导航。
- **产品要求（不是加一个聊天框）**：合同 08 的灵魂必须在页面上露出——
  - 回答带**出处（citation/evidence）**：能指出答案来自题池哪条记录；
  - **诚实拒答态**：检索落空（距离超阈值）时展示"资料未覆盖"类文案，而不是硬编；
  - 空手分支与审核闸（仅 approved 题目可被召回）是测试用例，也是页面状态。
- **建议挂载**：「05 知识问答」，归入练习区（见 §3 分区）。

### ③ 用户出口：退出登录 / 我的资料

- **现状**：右上角"林一舟"是死名字。`GET /user/me` 与 `POST /user/logout` 两端点无 UI 消费。
- **要求**：点开用户名至少有**退出登录**；顺带展示 me 资料（昵称/用户名等 VO 字段，天然脱敏）。
- **理由**：登录注册页已建成，登录后的"出口"缺位 = 认证链路没闭环。拦截器/互踢等安全机制（合同 02）全靠 logout 才能被用户触达。

> **不做的**：`/ai/chat` 是阶段二冒烟端点（合同 04 调试性质），**不建页面、不进导航**——不为调试接口造导航。

## 3. 导览图自身一致性修正（2 处）

1. **分区口径打架**：左下 legend 三区（简历区/面试区/报告区），页脚冒出"练习区"，复习队列四不管。
   **裁定**：定死四区——**简历区 / 面试区 / 报告区 / 练习区**；复习队列与知识问答均归练习区。命名一次统一，此后每张页面卡向分区归位，导航项编号顺延（01 简历 / 02 开始面试 / 03 面试报告 / 04 复习队列 / 05 知识问答）。
2. **"未开放"徽章语义失真**：03 报告、04 复习队列标"未开放"，但后端功能**均已完工签字**（合同 07/09）。冲刺周定档（STATUS 2026-11-09）本就是"阶段四/五功能逐个回填页面"——这两项是**回填对象**，不是新开发。导览图应区分「后端已有、前端待回填」与「真未开发」，否则排期评估会失真。建议徽章改双态：`待回填`（后端就绪）与 `未开发`（前后端皆无）。
