# 前端冲刺周需求单 v1.0（2026-11-23 签发，阶段五主体完工的收官幕）

## 0. 定位与纪律
- 技术栈定档：**Vue3 + Vite + ElementPlus**；骨架允许 AI 辅助生成，**接口对接、拦截器、状态逻辑必须手写**——那里的每一条规则都是你自己拍过的板
- 后端冻结：冲刺周不改后端 HTTP 面；前端接不通=后端 bug，修它，但要走 bug 上报，不许前端私自从侧门绕
- 联调工具现成：springdoc 文档页（swagger-ui）就是接口合同的可执行版
- 验收资产：冲刺周结束交 demo 录屏 + e2e 与前端并存的双回归绿

## 1. 页面清单（8 页封顶，超出的想法记 backlog）
1. 注册/登录（合并一页两 tab）
2. 简历列表（分页）+ 编辑页（新建/编辑共用表单）
3. 面试创建（选简历+题数）→ 排队/生成中轮询态
4. 答题页（主题列表+逐题作答/重交+追问按钮+追问树展开）
5. 复习面（今日到期列表+复习作答）
6. 报告页（summary+四分口径展示+weakPoints 点击溯源 evidence）
7. 掌握度双轴曲线（tag/category 切换）
8. 错题→复习的溯源页（可选，P2）

## 2. 十条需求（每条都有案底，前端是这些裁决的"用户可见层"）
- **F1** 追问按钮 enabled 条件=该题判分响应已返回且 score 非 null（②门案 #67）
- **F2** 错误码→文案映射表集中在一个模块（01 码表 v0.4：0/1/2/3/400/404/405/500）；成功 msg 永远"ok"，文案权在前端（06 J1/S13 家法）
- **F3** 渲染纪律：任何用户内容（题干/答案/姓名/comment）一律文本插值，**禁 v-html**（#66/S6 裁定）
- **F4** 轮询三态机：status 0/4 转圈+退避、1 进答题、2 看报告；reportStatus 0/1 提示生成中、3 引导 rebuild（rebuild 按钮加确认弹窗——它是烧钱操作）
- **F5** 分页控件 size 上限 50 镜像后端（防用户手滑，也防"前端不知道后端规矩"的病）
- **F6** 401 全局拦截→清 token 跳登录；404 资源类走"该资源不存在或已删除"话术（三态语义的用户侧翻译）
- **F7** 复习提交按钮防连点（前端 disable 只是体验辅佐——后端 CAS 才是主闸，F2① 案的原话）
- **F8** 追问树可视化：parent 链缩进即深度，strategy 角标（drill/angle/scaffold 三色徽章——X2 断言的 UI 版）
- **F9** token 用量展示：usage 回显字段摆进报告页脚（可观测性做进产品，444 收官数据的精神续作）
- **F10** 全部旋钮值不在前端硬编码（topK/上限类展示阈值从接口的配置类端点取，没有就记后端 bug 上报——旋钮进 Git 的家法延伸到"进接口"）

## 3. 交付定义（Done 的样子）
- 8 页跑通、十需求逐条勾、demo 录屏 3 分钟一镜到底（注册→简历→面试→答题→追问→交卷→报告→复习→曲线）
- `git status` 干净 + 每页一个 commit 的逻辑边界（feat(fe): 页面名）
- 冲刺周结束后：扩池计划 + 追问决策器 v2（热身混入，retry 升版那批）回炉排队
